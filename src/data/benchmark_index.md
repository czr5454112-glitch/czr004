# Phase1a Benchmark Index

Date: 2026-05-21

This index freezes the local benchmark files used by Phase1a. The map set and agent schedules are read from the LTM paper Figure 1. The 25 random scenario files per map are generated deterministically because the public MovingAI `scen-random.zip` files are too small for several frozen Figure 1 agent counts.

## Source Files

| Item | Local path | Status |
| --- | --- | --- |
| Map root | `external/lacam2/scripts/map/` | present |
| Generated random scen archive | `outputs/tmp/phase1a/generated/phase1a-generated-random.zip` | generated by `scripts/generate_phase1a_scenarios.py` |
| Generated scen manifest | `outputs/reports/phase1a_generated_scenarios_manifest.json` | generated metadata |
| Plus-3000 manifest | `configs/phase1a/manifest_plus_3000.jsonl` | base schedule plus 3000-agent extension on eligible maps |
| Scenario extraction cache | `outputs/tmp/phase1a/scen/` | generated by `scripts/run_phase1a_batch.ps1` |

The runner extracts scenarios into `outputs/tmp/phase1a/scen/` so the upstream submodule tree stays unchanged during normal runs.

## Validation Commands

```powershell
python scripts\generate_phase1a_scenarios.py --overwrite
python scripts\run_phase1a_batch.py --preflight
```

The generator uses base seed `20260522`, samples unique starts and unique goals from each map's largest connected free-cell component, and writes 25 `*-random-*.scen` entries for each Phase1a map.
